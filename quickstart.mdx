title: 'Quickstart'
description: 'Make your first request to the InsightThread News API in under a minute.'
---

## 1. Sign up

Create a developer account at
[newsapi.insighthread.com/login](https://newsapi.insighthread.com/login).
Developer accounts are separate from any consumer InsightThread app account.

## 2. Generate an API key

After signing in, go to your [dashboard](https://newsapi.insighthread.com/dashboard)
and click **Generate key**. Pick the key type:

- **Test** (`ik_test_…`) — sandbox with deterministic sample data, no quota,
  free forever. Use this for development.
- **Live** (`ik_live_…`) — real data, counts toward your plan's daily quota.

You'll see the raw key value **once**. Copy it immediately and store it
somewhere safe — we only keep a hash on our side.

## 3. Verify the key

The `/ping` endpoint is the simplest sanity check:

```bash
curl https://newsapi.insighthread.com/api/v1/ping \
  -H "Authorization: Bearer ik_test_REPLACE_ME"
```

Successful response:

```json
{
  "ok": true,
  "message": "Authenticated as \"my-first-key\"",
  "client": { "id": "...", "label": "my-first-key", "prefix": "ik_test_" },
  "served_at": "2026-05-21T10:00:00.000Z"
}
```

If you see a 401, double-check that the `Authorization` header is exactly
`Bearer <your-key>` with a single space.

## 4. Fetch news

```bash
curl "https://newsapi.insighthread.com/api/v1/news?limit=3&ticker=AAPL" \
  -H "Authorization: Bearer ik_test_REPLACE_ME"
```

You'll get back a paginated list of classified news events with sentiment
and impact scoring. See the [news endpoint](/api-reference/news) for the
full response shape and all filter parameters.

## 5. Promote to live

When you're ready for real data, generate a live key the same way (Generate
key → **Live**) and swap `ik_test_…` for `ik_live_…` in your code. Live
keys count against your daily quota — see [Rate limits](/rate-limits).
