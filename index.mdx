JSON feed — headlines tagged with event types, sentiment, confidence, and an
impact signal strength on a 1–5 scale.

## What you get

- **Real-time news feed** — classified by event type, sentiment, and signal strength
- **Ticker filtering** — `?ticker=AAPL` or `?tickers=AAPL,MSFT,GOOGL`
- **Event-type filtering** — earnings, legal actions, M&A, regulatory, and more
- **Sandbox keys** — free `ik_test_*` keys return deterministic sample data so you
  can integrate without burning live quota
- **Cursor pagination** — stable, opaque cursors for reliable backfill
