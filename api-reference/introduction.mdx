The InsightThread News API is a small, focused REST API. Three endpoints,
one auth scheme, one response envelope.

## Base URL

```
https://newsapi.insighthread.com/api/v1
```

## Authentication

Every request requires a Bearer token in the `Authorization` header:

```
Authorization: Bearer ik_live_aBc123xYz...
```

See [Authentication](/authentication) for how to create, rotate, and revoke keys.

## Response shape

Successful responses are JSON. Collection endpoints return a top-level
`count`, an optional `pagination` block, and `data`:

```json
{
  "count": 3,
  "pagination": { "next_cursor": "abc...", "has_more": true },
  "data": [ /* ... */ ]
}
```

Errors use a consistent envelope. See [Errors](/errors).

## Endpoints at a glance

| Method | Path        | Purpose                                                  |
|--------|-------------|----------------------------------------------------------|
| `GET`  | `/ping`     | Verify an API key                                        |
| `GET`  | `/events`   | List the valid event-type slugs you can filter on        |
| `GET`  | `/news`     | The main feed — paginated classified news articles       |

Pick an endpoint from the left sidebar to see request parameters,
example responses, and a working "Try it" panel.
